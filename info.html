Info Iuran Santri & Subsidi

💰 Besaran Iuran Reguler

  • Iuran Konsumsi : Rp 450.000 / bulan
  • Iuran Pondok : Rp 150.000 / bulan

* Total iuran per santri per bulan = Rp 600.000.

🤝 Kebijakan Subsidi & Keringanan

Pesantren memberikan keringanan iuran kepada santri dengan kriteria sebagai berikut:

  • Santri berprestasi.
  • Santri penghafal Al-Qur'an (hafalan minimal 2 juz), dan tergabung dalam Lembaga Tahfidz Qur'an NBS.
  • Santri yatim / piatu.
  • Dua bersaudara atau lebih yang belajar di pesantren ini.
  • Santri dari keluarga tidak mampu.
  • Subsidi khusus lainnya sesuai kebijakan pimpinan pondok.

Untuk pengajuan subsidi, harap menghubungi bagian bendahara atau pengasuh pondok dengan membawa bukti pendukung.

Semua data tersimpan secara online dan dapat diakses kapan saja.

Panduan Penggunaan Aplikasi

1. Login

Masukkan password untuk mengakses seluruh fitur.

2. Data Santri

Kelola data santri (ANGKATAN, NIS, NAMA). Data otomatis terurut berdasarkan NIS. Gunakan tombol Import Data untuk menempel data dari Excel (format: ANGK [TAB] NIS [TAB] NAMA).

3. Iuran Bulanan Santri (Iuran Konsumsi / Iuran Pondok)

Tentukan nominal iuran per bulan per kelas untuk 6 tahun (72 bulan). Auto-save setiap perubahan. Gunakan tombol Import Data untuk menempel data dengan format NIS nilai1 nilai2 ... (nilai diisikan ke kolom berurutan).

4. Input Transaksi

Pilih tipe Pemasukan atau Pengeluaran. Untuk pemasukan, centang Pembayaran Santri jika transaksi berasal dari santri (otomatis mengambil nominal dari iuran yang sudah ditetapkan). Pengeluaran dapat menambah beberapa baris sekaligus.

5. Riwayat Transaksi

Lihat semua transaksi, edit, filter tanggal, dan import multi baris dari spreadsheet. Tombol Sinkronisasi akan memperbarui nilai pemasukan pembayaran santri sesuai iuran terbaru.

6. Laporan BKU & Laporan per Santri

Laporan Buku Kas Umum (BKU) per bulan, dapat dicetak. Laporan per Santri menampilkan pembayaran santri per bulan per kelas.

7. Catatan Bendahara

Alternatif input pemasukan multi‑bulan dan pengeluaran. Setelah mengisi catatan, klik Import untuk memindahkan ke transaksi utama.

Tips: Data selalu auto-save. Gunakan tombol Refresh di setiap halaman jika ada perubahan dari luar.
